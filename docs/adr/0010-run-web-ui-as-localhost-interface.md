# Run the Web UI as a localhost interface

The v1 Web UI is a local interface to the local Core Service, served for localhost use rather than remote deployment. This follows the single-user local-first boundary and avoids adding accounts, public exposure, cloud sync, or remote knowledge-base permissions before the research and report-file workflow is stable.

V1 Web UI has three primary pages: Research Page, Tasks Page, and Knowledge Base Index Page. Research Page contains separate Local RAG and Web Research input areas plus current running task progress. It does not provide a combined "Run Both" action; users start Local RAG and Web Research separately if they want both. Local RAG and Web Research may run concurrently as separate tasks, so the page can show separate progress views for each active mode. It disables only conflicting actions: another Local RAG task while Local RAG is active, another Web Research task while Web Research is active, or Local RAG while `kb rebuild` is active. Tasks Page lists finished `completed` or `failed` tasks only. Knowledge Base Index Page shows `vault_path`, index status, file count, chunk count, last indexed time, and build or rebuild actions.
