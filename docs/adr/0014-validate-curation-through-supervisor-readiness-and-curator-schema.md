# Validate curation through Supervisor readiness and Curator schema

The workflow will not include a separate Final Check node in v1. Supervisor is responsible for routing to Curator only when the Blackboard has enough findings, finding-to-source links, source records, and a research saturation or hard-limit basis for curation, while Curator outputs must use Blackboard findings, preserve `source_ids` when available, and display the full source list. Workflow-internal research gaps are used for continuing execution or revising the plan, not for final report output.
