# Build v1 as a single-user local-first application

The v1 research agent is a single-user local-first application: it runs locally, uses a local SQLite state store, reads a user-configured Markdown Vault for Local RAG, and relies on user-configured model providers. We are deliberately deferring accounts, teams, remote knowledge-base permissions, collaborative editing, and multi-user isolation so v1 can focus on recoverable research tasks, Local Results, the independent Web Research workflow, and the local Web Report File.
